# Palette packs

Color palettes live in `themes/<slug>/` with a `colors.toml`. Apply with `theme-set` or Super+T.

These packs came from [basecamp/omarchy](https://github.com/basecamp/omarchy) `themes/` (colors only). This machine does not run omarchy-shell, their CLI, plymouth branding, or agent skills.

Extra wallpapers per slug: `backgrounds/<slug>/`.
Templates for extra apps: `themed/*.tpl` (neovim / vscode / claude templates are not applied).
Hooks: `hooks/<event>.d/` (`post-boot`, `theme-set`, `font-set`, `post-update`, `battery-low`).
